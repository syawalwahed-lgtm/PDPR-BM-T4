# BM Tahun 4 — Misi Golongan Kata

Permainan pembelajaran Bahasa Melayu Tahun 4 dengan nota ringkas, game ular, dan kuiz 25 soalan.

## Cara guna di komputer
Buka `index.html` menggunakan pelayar web moden.

## Cara terbitkan dengan GitHub Pages
1. Cipta repositori baharu di GitHub.
2. Muat naik `index.html` ke akar repositori (root).
3. Buka **Settings → Pages**.
4. Di bahagian **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, kemudian tekan **Save**.
6. Tunggu GitHub menerbitkan laman dan buka URL yang dipaparkan pada halaman Pages.
